Keyboard Navigation Guide

Communicator Keys

  • . or 1 : Register Dot
  • - or 2 : Register Dash
  • Space or 3 : Spacing/Commit
  • Enter or 4 : Speak Text
  • Backspace : Undo Last Input
  • Esc : Clear Current Text

Tutorial Mode Keys

  • T / t : Toggle Tutorial Mode
  • ← / [ : Previous Tutorial Letter
  • → / ] : Next Tutorial Letter
  • P / p : Play Tutorial Morse Sound
